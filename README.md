# Analog-To-Digital-Signal Conversion

## Objective
This project is to convert an analog signal such as speech to a digital signal such as an mp3 audio file exploring diigital signal processing paradigms ssuch as analysis of tradeoffs in gain‑tracking, filtering, sampling, SNR, and fixed‑point precision and software engineering paradigms such as Object-oriented programming, code reusability and code modularity.
## Project Status
This repository is under active development. Unit tested modules such as signal generator, automatic gain control, anti-aliasing filtering, and sampling have been implemented, while future improvements may include quantizer module, FIR digital filter, code refactoring, fixed-point analysis, and hardware-oriented optimization.
